# FSE Contextual Video Coaching — prototypes

Static, self-contained prototypes for the GG App training feature. No server, no login,
no external requests — each page is a single HTML file.

| Page | What it is |
|---|---|
| [Admin panel](https://pateldarshit-alt.github.io/fse-training-admin/) | Upload form with live phone preview across all nine widget views, targeting, performance triggers, frequency caps, assessment builder and the training library |
| [Viewer prototype](https://pateldarshit-alt.github.io/fse-training-admin/viewer.html) | The nine widget views on their host screens, plus the Trainings & Assessment hub |
| [PRD](https://pateldarshit-alt.github.io/fse-training-admin/prd.html) | Product requirements document, including the measurement event taxonomy |

These are prototypes for review. State lives in the browser only; nothing is written to a
server and no production data is reachable from them.
